# Common Go packages

[![PkgGoDev](https://pkg.go.dev/badge/go.skymeyer.dev/pkg)](https://pkg.go.dev/go.skymeyer.dev/pkg)

This repository contains common go packages that I use across multiple projects.
Make sure to use versioned tags when including these packages in other projects.
I will try to keep the packages backwards compatible, but I make no guarantees,
nor will I strictly follow semantic versioning.

```
go get go.skymeyer.dev/pkg@v1.0.1
```
